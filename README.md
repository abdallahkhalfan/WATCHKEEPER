# WATCHKEEPER Android

Smart reminder and preparation assistant.

## Features in this starter
- Work and event reminders
- Custom preparation checklists
- Wedding, baby shower, travel and work use cases
- Home location marking
- Departure Guard concept
- 30/60/90/120 second safety grace settings
- Emergency contact management

## Build
Codemagic uses `flutter create .`, `flutter pub get`, and `flutter build apk --release`.

Production-grade background geofencing and automatic emergency calling require additional native Android foreground/background service handling and device-specific permission testing.
